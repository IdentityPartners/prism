Connect Twenty CRM

Twenty is a free, open-source CRM. Sign up at twenty.com (30-day free trial, no card required), then connect Gmail + Google Calendar inside Twenty Settings → Accounts.

  1. 1Go to twenty.com → Start free trial → Create workspace
  2. 2Inside Twenty: Settings → Accounts → Add account → Continue with Google → connect Gmail + Google Calendar
  3. 3Inside Twenty: Settings → API & Webhooks → Generate API key → copy it
  4. 4Paste your API key and workspace URL below, then click Save
