Zoho Integration

Prism integrates with Zoho Mail, Calendar, CRM, and Social. To connect:

  1. Go to Settings → Zoho Integration
  2. Click the service you want to connect
  3. You will be redirected to Zoho to authorise access
  4. After authorising, you will be returned to Prism automatically

Important: Use the Global Zoho API console (api-console.zoho.com), not the EU console. The EU console produces intermittent authentication errors.

Cloudflare Tunnel (Local Models)

To use local Ollama models remotely:

  1. Install Cloudflare Tunnel on your Surface Pro 9
  2. Run: cloudflared tunnel --url http://localhost:11434
  3. Copy the tunnel URL (e.g. https://xxx.trycloudflare.com)
  4. Paste it in Settings → Routing → Ollama Tunnel URL

API Keys

All API keys are stored in Cloudflare Worker environment variables. To add or update a key:

  1. Go to the Cloudflare dashboard
  2. Navigate to Workers & Pages → prism-api → Settings → Variables
  3. Add or update the secret

Alternatively, use the Key Ingester in Settings to note keys for the next deployment.

Bluesky

Bluesky posting uses your app password (not your main password). Generate one at bsky.app → Settings → App Passwords. The handle and app password are already configured in the Worker.
